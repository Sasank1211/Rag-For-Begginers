# RAG For Beginners

This project demonstrates a Retrieval-Augmented Generation (RAG)
pipeline using LangChain, HuggingFace embeddings, ChromaDB and Ollama.

## Features

- Document ingestion
- Text chunking
- Vector embeddings
- Chroma vector database
- Similarity retrieval
- Multi-query retrieval
- Reciprocal Rank Fusion (RRF)
- Local LLM using Ollama

## Technologies

- Python
- LangChain
- HuggingFace
- ChromaDB
- Ollama
